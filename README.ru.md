# Bookmark Manager

[English](README.md) | Русский

Локальное веб-приложение для управления закладками с автоматическим извлечением метаданных, категориями, тегами, поиском, фильтрацией и импортом/экспортом. Построено на Python, FastAPI, SQLAlchemy и SQLite. Предназначено для самостоятельного развертывания и личного использования.

## Возможности

### Управление закладками
- Добавление закладки по URL; заголовок, описание, изображение Open Graph и favicon извлекаются автоматически
- Редактирование заголовка, описания, категории и тегов закладки
- Удаление закладок
- Добавление в избранное и удаление из него
- Архивация и восстановление закладок
- Открытие исходной страницы или копирование URL в буфер обмена

### Автоматическое извлечение метаданных
- Приоритет заголовка: `og:title` → `twitter:title` → HTML `<title>`
- Приоритет описания: `og:description` → `twitter:description` → `<meta name="description">`
- Извлечение изображения Open Graph и favicon
- Извлечение домена из URL
- Корректная отработка ошибок: если извлечение не удалось, ссылку всё равно можно сохранить вручную
- Ошибки на внешних сайтах не приводят к падению приложения

### Категории и теги
- Создание, редактирование и удаление категорий
- Назначение категорий закладкам
- Несколько тегов на одну закладку (связь «многие ко многим»)
- Фильтрация закладок по категории или тегу
- Защита от дубликатов имён категорий и тегов

### Поиск и фильтрация
- Полнотекстовый поиск по заголовку, описанию, URL и домену
- Фильтры: все закладки, избранное, архив, по категории, по тегу
- Сортировка: по дате добавления, по заголовку, по домену
- Пагинация

### Импорт и экспорт
- Импорт Netscape Bookmark HTML (экспорт закладок браузера)
- Структура папок браузера импортируется как категории
- Отчёт об импорте с количеством импортированных и пропущенных дубликатов
- Экспорт всех закладок обратно в Netscape Bookmark HTML

### Интерфейс
- Современный адаптивный интерфейс с тёмной и светлой темами
- Боковое меню с категориями и тегами
- Закладки в виде карточек
- Уведомления об успехе и ошибках
- Модальные окна создания и редактирования закладок

### Модели базы данных

**Bookmark** — `id`, `url`, `normalized_url` (уникальный), `title`, `description`, `domain`, `favicon_url`, `image_url`, `category_id`, `is_favorite`, `is_archived`, `created_at`, `updated_at`

**Category** — `id`, `name` (уникальное), `description`, `created_at`

**Tag** — `id`, `name` (уникальное, в нижнем регистре)

**BookmarkTag** — промежуточная таблица `bookmark_id`, `tag_id` с каскадным удалением

Бизнес-логика отделена от обработчиков API и HTML-шаблонов. Нормализация URL удаляет фрагменты, приводит схему и хост к нижнему регистру, сохраняя параметры запроса. Защита от SSRF блокирует localhost, адреса обратной связи, частные и зарезервированные диапазоны IP, а также схемы, отличные от HTTP/HTTPS.

## Использование

Запуск приложения:

```bash
python -m uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000 в браузере.

- **Веб-интерфейс**: http://127.0.0.1:8000/
- **Документация API (Swagger UI)**: http://127.0.0.1:8000/docs
- **Схема OpenAPI**: http://127.0.0.1:8000/openapi.json

Данные хранятся в `data/bookmarks.db` (SQLite). Закладки сохраняются между перезапусками.

### Основные эндпоинты REST API

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/api/bookmarks` | Список закладок (поиск, фильтрация, сортировка, пагинация) |
| POST | `/api/bookmarks` | Создание закладки |
| GET | `/api/bookmarks/{id}` | Получение закладки по ID |
| PUT | `/api/bookmarks/{id}` | Обновление закладки |
| DELETE | `/api/bookmarks/{id}` | Удаление закладки |
| POST | `/api/bookmarks/{id}/favorite` | Переключение избранного |
| POST | `/api/bookmarks/{id}/archive` | Архивация закладки |
| POST | `/api/bookmarks/{id}/restore` | Восстановление архивной закладки |
| GET | `/api/categories` | Список категорий |
| POST | `/api/categories` | Создание категории |
| GET | `/api/tags` | Список тегов |
| POST | `/api/tags` | Создание тега |
| POST | `/api/import` | Импорт Netscape Bookmark HTML |
| GET | `/api/export` | Экспорт закладок в Netscape Bookmark HTML |

### Импорт закладок из браузера

1. Экспортируйте закладки из браузера (Chrome, Firefox, Edge и др.) в файл HTML в формате Netscape Bookmark.
2. Откройте приложение Bookmark Manager.
3. Нажмите **Импорт / Экспорт** в боковом меню.
4. Выберите экспортированный HTML-файл и нажмите **Импортировать**.
5. Ознакомьтесь с отчётом об импорте: импортировано и пропущено дубликатов.

Структура папок из закладок браузера импортируется как категории.

## Тестирование

В проекте 66 автоматизированных тестов. Все тесты используют локальные HTML-фикстуры и моки — внешние сайты не задействуются.

```bash
python -m pytest
```

Тесты охватывают CRUD закладок, категории, теги, поиск, фильтрацию, сортировку, пагинацию, извлечение метаданных, защиту от SSRF, валидацию URL, импорт/экспорт и все эндпоинты API.

## Конфигурация

Приложение работает без дополнительной настройки. База данных SQLite создаётся автоматически в каталоге `data/` при первом запуске.

Переменные окружения не требуются. При необходимости настроек в будущем создайте файл `.env` на основе `.env.example` (не поставляется по умолчанию).

## Ограничения

- Приложение для одного пользователя, локальное развёртывание; нет аутентификации и поддержки нескольких пользователей.
- Извлечение метаданных носит «предупредительный» характер; некоторые страницы могут блокировать скрейпинг или не содержать тегов Open Graph.
- Внешние изображения не скачиваются; сохраняется только их URL.
- JavaScript на сторонних страницах не выполняется при извлечении метаданных.
- Предназначено для локального развёртывания; без дополнительного аудита безопасности не рекомендуется для публичного хостинга в интернете.
